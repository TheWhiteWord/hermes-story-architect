This story dashboard provides:

## Key Features:

1. **Interactive Navigation** - Tab-based navigation for Characters, Scenes, Locations, Plots, and Worlds
2. **Character Graph** - Visual network graph showing relationships between all entities
3. **Detailed Entity Views** - Rich detail panels for each entity type
4. **Hermes Integration** - "Ask Hermes" buttons throughout for contextual AI assistance
5. **Search & Filter** - Quick search functionality within entity lists
6. **Responsive Design** - Works in narrow preview panes and adapts to different screen sizes
7. **Theme Support** - Uses Hermes CSS variables for automatic light/dark theme support

## Main Views:

1. **List View**: Entity lists with clickable items that show detailed information
2. **Graph View**: Interactive character relationship graph using vis-network
3. **Detail Panel**: Context-specific information for each entity type

## Interactive Elements:

- Click any entity to see its details
- Navigate between related entities using clickable tags
- "Ask Hermes" buttons generate contextual prompts
- Search filters entities in real-time
- Graph nodes are clickable and navigate to entity details

The dashboard automatically loads `.story/index.yaml` and displays all story entities with their relationships, making it easy for writers to navigate their story world and get AI assistance when needed.
