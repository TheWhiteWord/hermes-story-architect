**Two template-literal artifacts, not intended text.** `story.js:106`
("Ask Hermes about this DASH.story") and `entity-panels.js:227` ("its role in
the DASH.story") carry the string `DASH.story` because a find/replace of
`story` → `DASH.story` was applied to the whole file. The prompt text they send
to the agent today is wrong.

**`DASH.story-section-title` defect.** The `class="DASH.story-section-title"`
emitted by `story.js:25,62,76,97`, `plots.js:50,54`, `scenes.js:102,106` is a
find/replace artifact. That class does not exist in any stylesheet — the real
class is `story-section-title` (`css/views.css:63`).

**`data-ent` protocol.** Seven sites carry the panel-wide `data-ent="type:id"`
protocol: `character-journey-tab.js:183,193`, `scene-beats-tab.js:38`,
`panel-tabs.js:92,93,152`, `entity-panels.js:20`. `panel-tabs.js:93` reads the
attribute (`ev.target.closest('[data-ent]')`) and `panel-tabs.js:94` routes it
through `D.panelTabs.openEntity`, whose parser lives at `openEntity`
(`panel-tabs.js:117`). The `data-ent` attribute is a separate protocol from
`data-hermes-send`.
Types: `character`, `location`, `world`, `relationship`, `scene`.
