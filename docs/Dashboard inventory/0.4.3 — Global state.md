## 0.4.3 — Global state

Everything the dashboard keeps between calls, in three tiers: the `DASH.*`
surface other modules reach, module-scoped values they cannot reach, and the
four payloads injected at assembly. Source for every line below is a `grep` over
`src/dashboard/`, plus the per-file read.

### Tier 1 — the `DASH.*` surface

23 files, **92 distinct `DASH.*` names** (`grep -rhoE 'DASH\.[A-Za-z_][A-Za-z0-9_]*' src/dashboard/ | sort -u | wc -l` → 92; 489 total references). `DASH.story` is the spine: **104
references across 16 files** (census: `colors.js:60`, `core.js:88-96`,
`script-view.js:97`, `utils.js:10`, `network.js:4,30`, `track-data.js` 3,
`value-graph.js` 5, `entity-panels.js` 34, `memory-dialog.js:6`,
`scene-beats-tab.js` 1, `locations.js:4`, `plots.js:4`, `relationships.js:5`,

inline handler).
